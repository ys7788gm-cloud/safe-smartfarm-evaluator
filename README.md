# SAFE 스마트팜 경제성 평가

`SAFE_ver1.0(2026.8.13.).xlsx`의 평가 구조와 계산식을 웹에서 자동 계산할 수 있도록 재구성한 공개용 도구입니다.

## 공개 페이지

[SAFE 스마트팜 경제성 평가 바로가기](https://ys7788gm-cloud.github.io/safe-smartfarm-evaluator/)

## 주요 기능

- 28개 사전체크와 상담 준비상태 자동 요약
- 20개 정성평가, 가중점수·등급·영역별 달성률 계산
- 2024년도 농산물소득조사 51개 품목 데이터
- 면적·작기·시설보정·3개 시나리오를 반영한 정상연도 소득 계산
- 2026년 농업종합자금 조건을 반영한 시설·개보수·운전자금 계산
- 30년 원금·이자·잔여소득 전망과 시나리오 그래프
- 브라우저 자동 저장, 반응형 화면, 인쇄·PDF 저장

## 로컬 실행

Node.js 22 이상에서 실행합니다.

```bash
npm ci
npm run dev
```

GitHub Pages용 정적 빌드는 다음과 같습니다.

```bash
npm run build:pages
```

빌드 결과는 `out/`에 생성됩니다. `main` 브랜치에 변경사항을 게시하면 GitHub Actions가 자동으로 Pages를 갱신합니다.

## 계산 범위와 유의사항

본 모델은 상담과 사업계획 검토를 위한 참고도구입니다. 투자 적정·부적정 또는 대출 승인 여부를 자동 판정하지 않습니다. 실제 지원액·금리·상환능력은 관계기관이 별도로 심사하며, 담보·신용·세금·생활비·감가상각·개별 에너지 구조는 별도 검토해야 합니다.
